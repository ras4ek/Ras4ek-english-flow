# 🧠 VocabMaster — English Vocabulary Trainer

Полностью переработанный тренажёр английских слов с системой интервального повторения (SRS), статистикой, PWA и 4 режимами тестирования.

## ✨ Что улучшено (в 10 раз лучше оригинала)

| Фича | Оригинал | VocabMaster |
|------|----------|-------------|
| **Архитектура** | Один файл, спагетти-код | Модульная структура (ES6 классы) |
| **Алгоритм повторения** | Просто "знаю/не знаю" | SRS (SM-2): 4 уровня, интервалы 1мин→10мин→1день→4дня |
| **Режимы теста** | 1 (EN→RU выбор) | 4 режима: EN→RU, RU→EN, Аудио→RU, Печать ответа |
| **Статистика** | Прогресс-бар | Графики активности, распределение SRS, streak, daily goal |
| **Навигация** | Кнопки мышью | Клавиатура (пробел, стрелки, 1-4), свайпы на мобильных |
| **Данные** | Хардкод | Импорт/экспорт JSON, localStorage с резервным копированием |
| **Офлайн** | Нет | PWA + Service Worker, работает без интернета |
| **UI/UX** | Базовый | Адаптивный дизайн, тёмная тема, анимации, toast-уведомления |
| **Поиск** | Нет | Фильтрация по статусу + поиск по словам |
| **Слова на повторение** | Нет | Отдельная вкладка с автоматическим расчётом |

## 🚀 Как выложить на GitHub Pages

### Шаг 1: Создай репозиторий
1. Зайди на [github.com](https://github.com) и создай новый репозиторий (например, `vocab-trainer`)
2. Сделай его **Public** (или Private + GitHub Pro для Pages)

### Шаг 2: Загрузи файлы
**Вариант A — через браузер:**
1. В репозитории нажми `Add file` → `Upload files`
2. Перетащи ВСЕ файлы проекта (index.html, css/, js/, manifest.json, sw.js)
3. Нажми `Commit changes`

**Вариант B — через Git (рекомендуется):**
```bash
git clone https://github.com/ТВОЙ_НИК/vocab-trainer.git
cd vocab-trainer
# скопируй сюда все файлы проекта
git add .
git commit -m "Initial commit"
git push origin main
```

### Шаг 3: Включи GitHub Pages
1. В репозитории перейди в `Settings` → `Pages` (в левом меню)
2. В разделе **Build and deployment**:
   - Source: `Deploy from a branch`
   - Branch: `main` / `master` → папка `/ (root)`
3. Нажми `Save`
4. Через 1-2 минуты сайт будет доступен по адресу:
   `https://ТВОЙ_НИК.github.io/vocab-trainer/`

### Шаг 4: Установи на телефон (PWA)
- **iOS Safari:** Поделиться → «На экран Домой»
- **Android Chrome:** Меню → «Установить приложение»
- Теперь тренажёр работает как нативное приложение, даже без интернета!

## ⌨️ Горячие клавиши (вкладка Карточки)

| Клавиша | Действие |
|---------|----------|
| `Пробел` | Перевернуть карточку |
| `←` / `→` | Предыдущая / следующая |
| `1` | Оценка: Снова |
| `2` | Оценка: Сложно |
| `3` | Оценка: Хорошо |
| `4` | Оценка: Легко |

## 📁 Структура проекта

```
vocab-trainer/
├── index.html          # Главная страница
├── manifest.json       # PWA манифест
├── sw.js               # Service Worker (кэширование)
├── css/
│   └── style.css       # Стили + адаптивность
└── js/
    ├── data.js         # Словарь (легко расширить)
    ├── storage.js      # localStorage wrapper
    ├── srs.js          # Алгоритм интервального повторения
    ├── stats.js        # Статистика и streak
    ├── charts.js       # Canvas-графики
    └── app.js          # Главный контроллер
```

## 🛠 Как добавить свои слова

Отредактируй `js/data.js` или импортируй JSON через интерфейс. Формат JSON для импорта:

```json
{
  "custom": [
    {"word": "example", "transcription": "[ɪɡˈzɑːmpl]", "phonetics_ru": "игза́мпл", "translation": "пример", "example": "This is an example.", "category": "My Words"}
  ]
}
```
